Confidentialité

Votre activité reste sur votre Mac.

Awakepilot fonctionne sans compte, publicité, statistiques, suivi ni télémétrie.

RésuméDonnées localesRéseauDiagnosticsAutorisationsIntégrité

Résumé de confidentialité

  • Aucun compte Awakepilot requis.
  • Sans publicité, SDK de statistiques, pixel de suivi ni service de télémétrie.
  • Historique et préférences restent dans votre compte macOS.
  • Awakepilot ne vend ni ne partage de données personnelles.

Données stockées localement

Préférences, état de session, mesures récentes et historique limité restent dans votre compte macOS. Les règles enregistrées peuvent inclure noms Wi-Fi, identifiants de volumes, profils, appareils, serveurs DNS et réseaux IP.

L’historique ne contient ni texte ni sortie de commande. Drive Alive crée un petit marqueur .awakepilot-drive-alive sur chaque disque inscriptible choisi et le supprime à la désactivation.

Accès réseau

Depuis 0.14.2, Awakepilot vérifie la dernière version sur awakepilot.codentum.net et y télécharge les paquets signés. Les versions publiques antérieures utilisent GitHub Releases.

Le site est hébergé sur GitHub Pages. GitHub peut recevoir les données de connexion habituelles, dont l’adresse IP, selon sa propre politique. Awakepilot n’envoie aucun événement d’utilisation.

Rapports de diagnostic

Un rapport est créé uniquement à votre demande, à l’emplacement choisi. Aucun envoi automatique.

Les rapports excluent commandes, sorties, chemins, noms de Wi-Fi, volumes, profils, apps, processus et appareils, DNS, règles IP et historique. Relisez tout fichier avant de le partager avec l’assistance.

Autorisations système

Les notifications sont facultatives. Lire le nom Wi-Fi exige la localisation macOS ; Awakepilot ne demande ni ne stocke de coordonnées. Les sessions utilisent les API natives d’alimentation, sans accès administrateur en usage normal.

Le démarrage à l’ouverture de session utilise le service natif Apple. Le raccourci global ne nécessite ni Accessibilité ni surveillance du clavier.

Bluetooth exige l’autorisation macOS et vérifie localement les appareils jumelés connectés. USB, audio, DNS et IP utilisent les informations système locales.

Intégrité des versions

Les paquets officiels sont signés avec Developer ID, notariés par Apple et publiés avec leurs sommes SHA-256. L’historique public fournit notes et téléchargements.
