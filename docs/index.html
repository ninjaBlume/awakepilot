Five ready-made templates

Start with the work you do.

Software development

A build can run longer than you expect. Follow the process instead of estimating a timer each time.

The Build tools template watches xcodebuild or swift, allows display sleep, and sets a four-hour limit. For one specific command, use awakepilotctl run.

The template stops applying when neither watched process is running or the four-hour limit is reached. It does not cancel the build.

Video production

Keep an export running while the screen is off, without keeping the whole editing app open as your only signal.

The Video encoding template follows ffmpeg with display sleep allowed and a four-hour limit. For other encoders, choose their process name.

Protection from this rule ends when the watched process disappears or the limit is reached; it does not confirm a successful export.

File transfers and backups

A long copy can outlast a short timer. Follow the transfer process and choose external drives explicitly.

The File transfers template watches rsync for up to four hours. Drive Alive stays off; enable it separately only on writable drives you select.

This rule ends when rsync is no longer running or the limit is reached. A drive rule follows mounting, not completion of a copy.

Download and Presentation are the other two templates. Save named profiles for repeated work; export or import them between Macs. Importing saves profiles without applying them. Other jobs or rules can still keep the Mac awake.

Drive Alive, with guardrails

Keep your selected external drive active.

Awakepilot refreshes one tiny marker on the writable external drives you choose. It never overwrites another app’s file, and removes its own marker when Drive Alive is disabled—even after a drive reconnects.

  • Set a 5, 10, 15, 30, or 60 minute interval
  • See success and write errors in the app

Trust comes from visibility

Review starts, stops, and changes.

A wake utility should never leave you guessing. Awakepilot records meaningful transitions without flooding the timeline with every live CPU or network sample.

Tie wake protection to one command.

Available in the free tier. With Awakepilot open, run your command through awakepilotctl instead of guessing how long it will take.

/Applications/Awakepilot.app/Contents/MacOS/awakepilotctl run --name "Build" -- xcodebuild -scheme MyApp
1

Start the command

Awakepilot creates a named wake lease before the command starts.

2

See the active reason

The panel shows the lease name among the reasons keeping the Mac awake. Battery and thermal safeguards still apply.

3

Release that protection

When the command exits, its lease is released. Other sessions or jobs may remain active; macOS is not told to sleep immediately.

Example command, not a recording. Replace MyApp with your scheme. A lease lasts at most 24 hours by default; --ttl can shorten it. Expiry releases protection without cancelling the command.

Working with the lid closed

Default mode prevents automatic idle sleep. Closing the lid and choosing Sleep remain under macOS control; display sleep and screen locking are separate.

The optional closed-lid mode is off by default. While active, it also blocks Sleep from the Apple menu, including without an external display.
