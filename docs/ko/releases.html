0.15.0

최신2026년 10월 8일

계정 없는 의견 보내기와 선택적인 활성 설치 수 집계.

의견 양식

  • 문제를 신고하거나 개선 사항을 제안하고 Awakepilot 사용 경험을 알려 주세요. 계정이 필요하지 않습니다.
  • 메시지와 선택한 이메일은 Codentum L.L.C.에 전송되며 최대 180일 동안 보관됩니다. 의견은 설치 수 집계와 별도로 저장됩니다.

선택적인 설치 수 집계

  • 기본적으로 꺼져 있으며 버전 0.15.0부터 설정에서 사용할 수 있습니다. 켜면 Awakepilot이 열려 있는 동안 UTC 날짜마다 한 번 무작위 설치 코드를 보냅니다. 날짜와 비밀 키로 계산한 코드의 해시만 저장합니다. 이름, 이메일, 하드웨어 ID, 세션, 자동화 규칙, 시스템 측정값은 수집하지 않습니다. 참여 중인 활성 설치를 세며 Mac 두 대는 설치 두 건으로 계산됩니다.
  • 일별 기록은 90일 후 삭제됩니다. 끄면 전송을 중단하고 로컬 코드를 삭제하며 다음 연결 시 이전 기록 삭제를 요청합니다. 늦은 요청으로 기록이 복원되지 않도록 해시로 된 철회 표시를 90일 동안 보관합니다. 다시 켜면 새 코드를 만듭니다.

0.14.3

2026년 10월 8일

응답성이 향상된 VPN 확인, 간편한 자동화 설정 및 워크플로 프로필 이동을 지원합니다.

주요 변경 사항

  • VPN 감지가 이제 백그라운드에서 실행됩니다. 결과 캐시와 2초 제한 시간을 사용해 인터페이스의 응답성을 유지합니다.
  • 동영상 인코딩, 빌드, 파일 전송, 다운로드, 프레젠테이션을 위한 자동화 템플릿 5개를 추가했습니다. 템플릿을 저장해도 현재 규칙이나 세션은 변경되지 않습니다.
  • 자동화 설정을 섹션별로 나누고 USB, Bluetooth, 오디오, DNS 및 IP 설정을 펼쳐서 볼 수 있도록 구성했습니다.
  • 전체 프로필을 버전이 지정된 JSON 파일로 내보내고 가져올 수 있습니다. 가져오기는 기존 프로필, 활성 규칙 및 세션을 유지하며 중복된 프로필 이름을 변경합니다. 잘못된 파일은 변경 사항을 적용하기 전에 거부됩니다.
  • 내보낸 프로필에는 설정한 기기 및 네트워크 이름이 포함될 수 있습니다. 프로필을 적용하기 전에 가져온 Drive Alive 설정을 검토하세요.
  • 홈, 지원, 가격 및 릴리스 노트 링크가 이제 인터페이스 언어 10개와 지역별 언어 기본 설정을 따릅니다.

0.14.2

2026년 10월 8일

10개 인터페이스 언어와 Awakepilot 사이트에서 제공하는 업데이트.

새 언어 4개

  • 이탈리아어, 브라질 포르투갈어, 일본어, 한국어 추가. 이제 10개 언어를 지원합니다.
  • 각 새 언어의 표시 문구 559개와 macOS 권한 설명 2개를 모두 번역했습니다.
  • 이탈리아어와 포르투갈어의 긴 선택 문구를 줄여 전체가 보이게 했습니다.

업데이트와 다운로드

  • 업데이트 확인과 공식 패키지 다운로드는 awakepilot.codentum.net을 사용합니다.
  • 앱 언어에 따라 영어, 독일어, 튀르키예어 노트를 열며 다른 언어는 영어를 사용합니다.
  • 이전 설치를 위한 GitHub Releases는 유지합니다. SHA-256, 앱 식별 정보, Developer ID, Gatekeeper 검증도 유지합니다.

0.14.1

2026년 10월 1일

안정적인 앱 내 업데이트와 명확한 제어.

안정적인 업데이트

  • 정보 및 업데이트 화면이 앱 종료를 막아 설치가 멈추는 문제를 수정했습니다. 설치 프로그램에 넘기기 전에 화면을 닫습니다.
  • 종료를 취소하면 5초 뒤 해결 방법이 있는 오류를 표시합니다. 설치 도우미도 30초 뒤 기다림을 끝냅니다.
  • 앱 실행 중 24시간마다, 확인 시각이 지난 복귀 후에도 확인합니다. 자동 확인 실패는 1시간 뒤 재시도하며 수동 확인도 가능합니다.
  • 업데이트 준비 중 시작된 것을 포함한 실행 중 작업은 설치를 막습니다.

명확한 제어와 도움말

  • 영어, 독일어, 스페인어, 프랑스어, 아제르바이잔어, 튀르키예어의 화면 동작, 활동 한도, 조건 판정, 시간 설명을 개선했습니다.
  • 긴 설정 설명의 줄바꿈을 개선했습니다.
  • 영어, 독일어, 튀르키예어 사이트, 지원 페이지, 이미지를 갱신했습니다.
0.14.0 이전 버전에서 업데이트

첫 업데이트는 기존에 설치된 업데이트 기능을 사용합니다. 업데이트 설치 중이 1분 넘게 유지되면 정보 및 업데이트를 닫고 메뉴 막대에서 종료하세요. 준비된 업데이트가 완료되고 앱이 다시 실행될 수 있습니다. 안 되면 다운로드 버튼으로 최신 공식 DMG를 설치하세요. 수정은 0.14.1 설치 후 적용됩니다.

0.14.0

2026년 10월 1일

연결된 하드웨어, 오디오 출력, 활성 네트워크 설정으로 자동화를 확장합니다.

주요 변경 사항

  • 선택한 USB 기기 연결 시 시작.
  • 선택한 페어링 Bluetooth 기기의 연결과 해제 감시.
  • 선택한 macOS 오디오 출력이 사용되는 동안 세션 유지.
  • 활성 설정에서 선택한 DNS 서버 주소 확인.
  • 정확한 IPv4, IPv6 주소와 CIDR 네트워크 확인.
  • 새 조건마다 별도의 프로필, 화면 정책, 최대 시간 지정.
  • 새 하드웨어와 네트워크 규칙을 재사용 프로필에 저장.
  • 영어, 독일어, 스페인어, 프랑스어, 아제르바이잔어, 튀르키예어 전체 인터페이스 지원.
  • 큰 설치 아이콘, 방향 화살표, Retina 배경이 있는 디스크 이미지.

개인정보 보호와 권한

USB와 오디오는 로컬 macOS API를 사용합니다. Bluetooth는 표준 권한을 받아 연결된 페어링 기기만 확인합니다. 기기 이름, DNS, IP 규칙은 macOS 계정에 남습니다. 진단은 규칙 수와 활성 상태만 포함하고 이름, DNS, IP 규칙, 활동 기록은 제외합니다.

0.13.0

2026년 10월 1일

네트워크와 외장 저장 장치로 자동화를 확장하고 전체 설정을 위한 재사용 프로필을 도입합니다.

주요 변경 사항

  • 선택한 Wi-Fi 네트워크에서 시작.
  • 모든 활성 macOS VPN 서비스 감시.
  • 선택한 외장 볼륨 마운트 시 시작.
  • Drive Alive가 선택한 쓰기 가능 볼륨의 자체 파일을 5~60분 간격으로 갱신.
  • 전체 설정을 이름 있는 프로필로 저장하고 복원.
  • 앱, 프로세스, 일정, CPU, 네트워크, 전원, 화면, Wi-Fi, VPN, 드라이브마다 별도 프로필, 화면 정책, 시간 한도 지정.
  • 의미 있는 시작, 중지, 일시 정지, 조건 변화를 로컬 기록에서 확인.
  • 단축어의 기본 검색을 위한 App Intents 및 App Shortcuts 제공자 포함.

보안과 개인정보 보호

Wi-Fi, 볼륨, 프로필 이름은 macOS 계정에 남습니다. Drive Alive는 서명된 자체 소유 표시 파일만 변경하고 비활성화 시 삭제합니다. 진단은 Wi-Fi, 볼륨, 앱, 프로세스, 프로필 이름을 제외합니다.

설치 프로그램 개선 — 2026년 10월 1일

서명 및 공증 DMG에 큰 앱과 응용 프로그램 아이콘, 명확한 화살표, Retina 배경을 적용했습니다. 앱은 0.13.0이며 ZIP은 그대로입니다. DMG의 SHA-256 체크섬을 갱신했습니다.

0.12.0

2026년 10월 1일

외부 제어, 프로세스 자동화, 긴 명령을 위한 시간 제한 보호 추가.

주요 변경 사항

  • 단축어 URL 열기로 시작, 중지, 전환, 연장.
  • awakepilot:// URL 체계와 포함된 CLI awakepilotctl.
  • 소유 프로세스 종료 시 자동 해제되는 시간 제한 보호.
  • awakepilotctl run -- <command>로 명령 실행 내내 보호.
  • 설정 가능한 터미널 프로세스 규칙.
  • 하나 또는 모든 조건의 일치 판정.
  • 전원 어댑터와 연결된 디스플레이 자동화.
  • 위험한 온도에서 일시 정지하고 자동 세션 최대 시간 적용.
  • 메뉴 막대의 남은 시간과 자동 세션 문구 선택 표시.

보안과 개인정보 보호

보호는 24시간으로 제한됩니다. awakepilotctl run은 소유 프로세스 종료 시 해제하고 고아 보호도 정리합니다. 프로세스 규칙은 실행 파일 이름만 비교하며 명령과 출력은 저장하지 않습니다. 진단은 감시 앱과 프로세스 이름을 제외합니다.

  • 릴리스 및 기기 검증 문서.
