계정, 광고, 분석, 추적, 원격 측정 없이 작동합니다.

요약로컬 데이터네트워크진단권한구매 및 지원무결성

개인정보 보호 요약

  • Awakepilot 계정은 필요 없습니다.
  • 광고, 분석 SDK, 추적 픽셀, 원격 측정 서비스가 없습니다.
  • 활동 기록과 설정은 macOS 사용자 계정에 남습니다.
  • 개인정보를 판매하거나 공유하지 않습니다.

로컬 저장 데이터

설정, 세션 상태, 최근 측정, 제한된 기록은 macOS 계정에 저장합니다. 규칙은 Wi-Fi 이름, 볼륨 ID, 프로필, 기기 ID, DNS, IP 네트워크를 포함할 수 있습니다.

명령과 출력은 활동 기록에 쓰지 않습니다. Drive Alive는 선택한 쓰기 가능한 드라이브에 작은 .awakepilot-drive-alive 표시 파일을 만들고 비활성화 시 삭제합니다.

네트워크 접근

0.14.2부터 awakepilot.codentum.net에서 최신 버전을 확인하고 같은 사이트에서 서명된 패키지를 받습니다. 이전 공개 버전은 GitHub Releases를 사용합니다.

사이트는 GitHub Pages에서 호스팅합니다. GitHub는 자체 정책에 따라 IP 등 일반 연결 정보를 받을 수 있습니다. Awakepilot는 사용 이벤트를 보내지 않습니다.

진단 보고서

직접 요청하고 저장 위치를 선택할 때만 생성합니다. 자동 업로드는 없습니다.

명령, 출력, 경로, Wi-Fi, 볼륨, 프로필, 앱, 프로세스, 기기 이름, DNS, IP 규칙, 활동 기록은 제외합니다. 지원팀에 공유하기 전에 검토하세요.

시스템 권한

알림은 선택 사항입니다. Wi-Fi 이름을 읽으려면 위치 권한이 필요하지만 좌표를 요청하거나 저장하지 않습니다. 세션은 macOS 기본 전원 API를 사용하며 일반 사용 중 관리자 권한이 필요 없습니다.

로그인 시 시작은 Apple 기본 서비스 등록을 사용합니다. 전역 단축키는 손쉬운 사용이나 키보드 감시 권한이 필요 없습니다.

Bluetooth는 macOS 권한을 받아 연결된 페어링 기기를 로컬에서 확인합니다. USB, 오디오, DNS, IP는 로컬 시스템 정보를 사용합니다.

구매 및 지원

구매 기록, 지원 문의 및 결제 제공업체의 데이터에 대해서는 Codentum 개인정보 처리방침을 확인하세요. 유료 결제는 준비 중입니다.
