활동은 Mac에 남습니다. 설치 집계는 선택 사항이며 기본적으로 꺼져 있습니다. 의견은 양식을 제출할 때만 전송됩니다.

개인정보 보호 요약

  • Awakepilot 계정은 필요 없습니다.
  • 광고나 행동 추적이 없습니다. 설치 집계는 선택 사항입니다.
  • 활동 기록과 설정은 macOS 사용자 계정에 남습니다.
  • Awakepilot은 개인 데이터를 판매하지 않습니다.

로컬 저장 데이터

설정, 세션 상태, 최근 측정, 제한된 기록은 macOS 계정에 저장합니다. 규칙은 Wi-Fi 이름, 볼륨 ID, 프로필, 기기 ID, DNS, IP 네트워크를 포함할 수 있습니다.

명령과 출력은 활동 기록에 쓰지 않습니다. Drive Alive는 선택한 쓰기 가능한 드라이브에 작은 .awakepilot-drive-alive 표시 파일을 만들고 비활성화 시 삭제합니다.

네트워크 접근

0.14.2부터 awakepilot.codentum.net에서 최신 버전을 확인하고 같은 사이트에서 서명된 패키지를 받습니다. 이전 공개 버전은 GitHub Releases를 사용합니다.

사이트는 GitHub Pages에서 호스팅합니다. GitHub는 자체 정책에 따라 IP 등 일반 연결 정보를 받을 수 있습니다. Awakepilot는 사용 이벤트를 보내지 않습니다.

진단 보고서

직접 요청하고 저장 위치를 선택할 때만 생성합니다. 자동 업로드는 없습니다.

명령, 출력, 경로, Wi-Fi, 볼륨, 프로필, 앱, 프로세스, 기기 이름, DNS, IP 규칙, 활동 기록은 제외합니다. 지원팀에 공유하기 전에 검토하세요.

시스템 권한

알림은 선택 사항입니다. Wi-Fi 이름을 읽으려면 위치 권한이 필요하지만 좌표를 요청하거나 저장하지 않습니다. 세션은 macOS 기본 전원 API를 사용하며 일반 사용 중 관리자 권한이 필요 없습니다.

로그인 시 시작은 Apple 기본 서비스 등록을 사용합니다. 전역 단축키는 손쉬운 사용이나 키보드 감시 권한이 필요 없습니다.

Bluetooth는 macOS 권한을 받아 연결된 페어링 기기를 로컬에서 확인합니다. USB, 오디오, DNS, IP는 로컬 시스템 정보를 사용합니다.

선택적인 설치 수 집계

기본적으로 꺼져 있으며 버전 0.15.0부터 설정에서 사용할 수 있습니다. 켜면 Awakepilot이 열려 있는 동안 UTC 날짜마다 한 번 무작위 설치 코드를 보냅니다. 날짜와 비밀 키로 계산한 코드의 해시만 저장합니다. 이름, 이메일, 하드웨어 ID, 세션, 자동화 규칙, 시스템 측정값은 수집하지 않습니다. 참여 중인 활성 설치를 세며 Mac 두 대는 설치 두 건으로 계산됩니다.

일별 기록은 90일 후 삭제됩니다. 끄면 전송을 중단하고 로컬 코드를 삭제하며 다음 연결 시 이전 기록 삭제를 요청합니다. 늦은 요청으로 기록이 복원되지 않도록 해시로 된 철회 표시를 90일 동안 보관합니다. 다시 켜면 새 코드를 만듭니다.

의견 양식

주제, 메시지, 언어, 선택적인 이메일과 앱 버전을 보냅니다. 문제와 제안을 검토하고 요청된 경우 답변하는 데 사용합니다. 최대 180일 동안 보관하며 필요 없어지면 더 일찍 삭제합니다. 열람, 수정, 삭제는 hello@codentum.net으로 요청하세요. 이메일을 제공하지 않았다면 접수 번호를 알려 주세요. 의견은 설치 코드와 연결하지 않습니다.

Cloudflare가 집계 및 의견 서비스를 호스팅하며 요청을 전달하고 보호하기 위해 IP 주소 등의 연결 정보를 처리합니다. 집계와 의견 데이터베이스에는 IP 주소를 저장하지 않습니다. 양식은 스팸 방지를 위해 Cloudflare Turnstile을 사용합니다. 이 서비스의 요청 로그는 비활성화되어 있습니다. 광고나 행동 프로필을 만들지 않습니다.

구매 및 지원

미국 와이오밍주에 등록된 Codentum L.L.C.가 Awakepilot을 제공합니다. hello@codentum.net으로 보내기로 선택한 지원 메시지와 첨부 파일을 받으며, 제공하신 구매 이메일 주소, 주문 ID 및 구매 날짜도 포함됩니다. 전체 카드 정보, 보안 코드, 비밀번호 또는 라이선스 키를 보내지 마세요.

유료 결제는 준비 중이며 아직 제공되지 않습니다. 판매가 시작되면 구매자의 이메일 주소, 주문 ID, 결제 상태 및 라이선스 권한을 라이선스 제공과 복원, 환불 및 회계 의무 이행에 사용합니다. 결제 제공업체는 자체 개인정보 처리방침에 따라 결제 정보를 처리하며 결제 전에 표시됩니다. 앱의 로컬 활동은 이러한 기록의 일부로 업로드되지 않습니다.

문의에 답변하고 적절한 지원 기록을 유지하는 데 필요한 기간 동안 서신을 보관합니다. 판매 시작 후 구매 및 라이선스 기록은 라이선스 지원과 법적 의무에 필요한 기간 동안 보관됩니다. 관련 법에 따라 hello@codentum.net으로 접근, 수정 또는 삭제를 요청할 수 있습니다. 보내신 정보는 미국 및 호스팅·이메일 제공업체가 운영하는 국가에서 처리될 수 있습니다. 개인정보를 판매하지 않습니다. 호스팅된 라이선스 제공 또는 기기 활성화 서비스는 아직 배포되지 않았으며 도입 전에 이 안내를 업데이트합니다.
