Awakepilot 설치

공식 공증 DMG를 열고 Awakepilot를 응용 프로그램 폴더로 드래그하세요. “로그인 시 시작”을 켜기 전에 그 폴더에서 실행하세요.

Apple Silicon 및 Intel Mac의 macOS 13 이상을 지원합니다.

메뉴 막대 아이콘 찾기

Awakepilot는 메뉴 막대에서 실행되며 Dock에 표시되지 않습니다. 화면 오른쪽 위의 시계 아이콘을 찾으세요.

  • 왼쪽 클릭은 간결한 제어 패널을 엽니다.
  • 오른쪽 클릭은 세션, 빠른 타이머, 시스템 지표 설정을 엽니다.
  • 채워진 시계는 Mac의 잠자기를 방지하고 있다는 뜻입니다.

“세션 중지”는 해당 세션을 끝내고 재개할 때까지 규칙을 일시 정지합니다. 명령이나 전송은 취소되지 않으며 Mac을 계속 깨어 있게 할 수 있습니다. 보호 종료가 즉시 잠자기를 실행하지는 않습니다.

긴 작업 자동화

앱, 프로세스, 일정, CPU, 네트워크, 전원, 화면, Wi-Fi, VPN, USB, Bluetooth, 오디오, DNS, IP, 외장 드라이브 규칙을 사용하세요. 한 조건 또는 모든 조건의 동시 충족을 선택합니다. 전체 프로필을 저장하거나 조건마다 프로필, 화면, 시간 한도를 지정하세요.

macOS가 Wi-Fi 이름을 보호하므로 위치 서비스 권한이 필요합니다. Drive Alive는 선택한 쓰기 가능한 드라이브의 자체 숨김 파일만 갱신하며 비활성화 시 제거합니다.

명령 실행 시간을 정확히 추적하려면 실행하세요: /Applications/Awakepilot.app/Contents/MacOS/awakepilotctl run --name "My job" -- command. 해당 명령이 끝나면 그 보호가 종료됩니다. 다른 작업은 Mac을 계속 깨어 있게 할 수 있습니다.

자동화에서 기기와 네트워크 규칙을 선택하세요. Bluetooth는 macOS 권한이 필요하며, 오디오는 현재 출력을 따릅니다. DNS는 정확한 주소를 비교하고 IP는 IPv4, IPv6, CIDR을 지원합니다.

앱 규칙은 앱 종료까지 지속되며 창을 닫는 것만으로는 끝나지 않습니다. CPU와 네트워크는 활동을 측정하고 작업 완료는 확인하지 않습니다. “모든 조건”에서는 하나가 끝나면 규칙이 해제됩니다. 독립 작업은 계속 잠자기를 막을 수 있습니다.

체험, 활성화, 구매 복원

Pro는 14일 체험을 제공합니다. 이후에도 수동 세션은 이용 가능하며, 자동화 설정은 Mac에 남지만 실행하려면 Pro가 필요합니다.

  • Awakepilot → 설정 → 라이선스 및 Pro를 여세요.
  • 전체 라이선스 키를 붙여 넣고 라이선스 활성화를 선택하세요.
  • 개인용 영구 라이선스는 Mac 최대 2대에서 사용할 수 있습니다.
  • 새 Mac에서 활성화하기 전에 기존 Mac에서 제거하세요.

공개 GitHub 이슈에 키, 구매 이메일, 거래 ID를 올리지 마세요. 구매 복원은 Pro 결제 시작 시 비공개 고객 포털을 이용할 예정입니다.

Mac이 계속 잠자기로 전환되면

녹색 상태 패널을 확인하세요. 배터리 한도, 어댑터, UPS 규칙이 세션을 일시 정지할 수 있습니다.

MacBook 덮개 닫기, Apple 메뉴의 잠자기 선택, 위험한 배터리 부족은 여전히 잠자기를 실행할 수 있습니다. Awakepilot는 이 안전 동작을 무시하지 않습니다.

화면 끄기는 시스템 잠자기 및 화면 잠금과 별개입니다. Mac은 계속 일할 수 있으며 macOS 잠금 설정은 유지됩니다.

업데이트와 첫 실행

오른쪽 클릭 메뉴의 정보 및 업데이트 에서 업데이트를 확인하세요. 설치 전에 체크섬, 앱 식별 정보, Developer ID 서명, Gatekeeper 승인을 검증합니다.

수동 다운로드한 복사본을 macOS가 차단하면 제거하고 릴리스 페이지의 공식 공증 DMG를 설치하세요.

앱이 열린 동안 24시간마다, 또는 확인 시각이 지난 잠자기 복귀 후 자동 확인합니다. 설치 시점은 직접 선택합니다. 다운로드는 보통 1분 미만이며 느린 연결에서는 더 걸릴 수 있습니다.

0.14.0 이전 버전의 업데이트가 업데이트 설치 중 에서 1분 넘게 멈추면 닫으세요: 정보 및 업데이트. 그런 다음 메뉴 막대에서 Awakepilot를 종료하세요. 준비된 업데이트가 완료되고 앱이 다시 실행될 수 있습니다. 안 되면 최신 공식 DMG를 설치하세요. 0.14.1은 이후 업데이트의 이 문제를 수정합니다.

진단 보고서 만들기

여세요: 정보 및 업데이트. 그런 다음 선택하세요: 진단 보고서 저장. 공유 전에 JSON 파일을 검토하세요.

명령, 출력, 경로, Wi-Fi 및 볼륨 이름, 프로필, 감시 앱과 프로세스, 기기 이름, DNS, IP 규칙, 활동 기록은 제외합니다.
