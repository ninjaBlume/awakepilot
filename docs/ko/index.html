Mac을 깨어 있게 할 때를 선택하세요.

잠자기를 막고 있는 앱, 프로세스, 조건을 확인하세요. 규칙이 더 이상 성립하지 않고 다른 작업도 보호를 필요로 하지 않으면 일반 잠자기 설정이 적용됩니다.

앱이 열려 있다고 작업이 계속된다는 뜻은 아닙니다. CPU나 네트워크 활동이 줄어도 작업 완료를 확인할 수 없습니다.

  • ✓
    앱, 프로세스, 연결실행 중인 앱, 터미널 도구, Wi-Fi, VPN, 외장 드라이브와 명령을 따릅니다.
  • ✓
    이름 있는 자동화 프로필규칙 묶음을 저장하고 사무실, 이동, 렌더링, 다운로드 작업에 맞게 전환하세요.
  • ✓
    조건별 설정조건마다 세션 프로필, 화면 동작, 시간 한도를 선택하세요.
  • ✓
    확인 가능한 기록과 안전 한도시작, 중지, 변경을 확인하면서 배터리와 온도 한도를 유지합니다.
