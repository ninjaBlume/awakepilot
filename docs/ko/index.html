Mac을 깨어 있게 할 때를 선택하세요.

반복 작업용 설정을 저장하세요. 다섯 가지 템플릿 중 하나로 시작하고 조건을 선택하면 Mac이 작업하는 동안 화면을 꺼둘 수 있습니다.

앱이 열려 있다고 작업이 계속된다는 뜻은 아닙니다. CPU나 네트워크 활동이 줄어도 작업 완료를 확인할 수 없습니다.

  • ✓
    앱, 프로세스, 연결실행 중인 앱, 터미널 도구, Wi-Fi, VPN, 외장 드라이브와 명령을 따릅니다.
  • ✓
    이름 있는 자동화 프로필규칙 묶음을 저장하고 사무실, 이동, 렌더링, 다운로드 작업에 맞게 전환하세요.
  • ✓
    조건별 설정조건마다 세션 프로필, 화면 동작, 시간 한도를 선택하세요.
  • ✓
    확인 가능한 기록과 안전 한도시작, 중지, 변경을 확인하면서 배터리와 온도 한도를 유지합니다.

평소 하는 작업부터 시작하세요.

소프트웨어 개발

빌드는 예상보다 오래 걸릴 수 있습니다. 매번 타이머 시간을 추측하지 말고 프로세스를 추적하세요.

빌드 도구 템플릿은 xcodebuild 또는 swift를 추적하고 화면 잠자기를 허용하며 4시간 제한을 설정합니다. 특정 명령 하나에는 awakepilotctl run을 사용하세요.

추적 중인 프로세스가 모두 종료되거나 4시간 제한에 도달하면 템플릿 조건이 끝납니다. 빌드 자체를 취소하지는 않습니다.

동영상 제작

편집 앱이 열려 있다는 사실만 신호로 삼지 않고, 화면이 꺼진 상태에서도 내보내기를 계속할 수 있습니다.

동영상 인코딩 템플릿은 ffmpeg를 추적하고 화면 잠자기를 허용하며 4시간으로 제한합니다. 다른 인코더에는 해당 프로세스 이름을 선택하세요.

추적 중인 프로세스가 사라지거나 제한에 도달하면 이 규칙의 보호가 끝납니다. 내보내기 성공을 확인하는 기능은 아닙니다.

파일 전송 및 백업

긴 복사는 짧은 타이머 시간을 넘길 수 있습니다. 전송 프로세스를 추적하고 외장 드라이브를 직접 선택하세요.

파일 전송 템플릿은 rsync를 최대 4시간 추적합니다. Drive Alive는 꺼져 있습니다. 선택한 쓰기 가능한 드라이브에서만 별도로 켜세요.

rsync가 더 이상 실행되지 않거나 제한에 도달하면 규칙이 끝납니다. 드라이브 규칙은 연결 상태를 추적하며 복사 완료를 확인하지 않습니다.

나머지 두 템플릿은 다운로드와 프레젠테이션입니다. 반복 작업용 이름 있는 프로필을 저장하고 Mac 사이에서 내보내거나 가져오세요. 가져오기는 적용하지 않고 프로필만 저장합니다. 다른 작업이나 규칙이 Mac을 계속 깨어 있게 할 수 있습니다.

명령 하나에 깨어 있기 보호를 연결하세요.

무료 등급에서도 사용할 수 있습니다. Awakepilot을 연 상태에서 소요 시간을 추측하는 대신 awakepilotctl로 명령을 실행하세요.

/Applications/Awakepilot.app/Contents/MacOS/awakepilotctl run --name "Build" -- xcodebuild -scheme MyApp
1

명령 시작

Awakepilot은 명령이 시작되기 전에 이름 있는 깨어 있기 사용권을 만듭니다.

2

활성 이유 확인

패널은 Mac을 깨어 있게 하는 이유에 사용권 이름을 표시합니다. 배터리 및 온도 보호는 계속 적용됩니다.

3

해당 보호 해제

명령이 끝나면 해당 사용권이 해제됩니다. 다른 세션이나 작업은 계속 활성 상태일 수 있으며, macOS에 즉시 잠자기를 지시하지 않습니다.

예시 명령이며 녹화가 아닙니다. MyApp을 자신의 스킴으로 바꾸세요. 사용권은 기본적으로 최대 24시간이며 --ttl로 줄일 수 있습니다. 만료는 명령을 취소하지 않고 보호만 해제합니다.

덮개를 닫고 작업하기

기본 모드는 유휴 상태의 자동 잠자기를 막습니다. 덮개 닫기와 잠자기 선택은 macOS가 제어하며, 화면 잠자기와 화면 잠금은 별개입니다.

선택 사항인 덮개 닫기 모드는 기본적으로 꺼져 있습니다. 활성화되면 외장 디스플레이가 없어도 작동하며 Apple 메뉴의 잠자기도 막습니다.
