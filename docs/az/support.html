Awakepilot-u quraşdırın

Rəsmi təsdiqlənmiş DMG-ni açın və Awakepilot-u Applications qovluğuna sürükləyin. “Girişdə başlat” seçməzdən əvvəl tətbiqi oradan açın.

Awakepilot Apple Silicon və Intel Mac-larda macOS 13 və sonrakı versiyaları dəstəkləyir.

Menyu sətrinin ikonunu tapın

Awakepilot menyu sətrində işləyir, Dock-da görünmür. Ekranın yuxarı sağında saat ikonunu axtarın.

  • Sol klik yığcam paneli açır.
  • Sağ klik sessiyaları, sürətli müddətləri və sistem göstəricilərini açır.
  • Dolu saat Mac-ın aktiv şəkildə oyaq saxlandığını göstərir.

“Sessiyanı dayandır” sessiyanı bitirir və qaydaları siz davam etdirənədək saxlayır. Əmr və köçürmələr ləğv olunmur, Mac-ı oyaq saxlaya bilər. Qoruma bitəndə Mac dərhal yatmır.

Uzun işləri avtomatlaşdırın

Tətbiq, proses, cədvəl, CPU, şəbəkə, enerji, ekran, Wi-Fi, VPN, USB, Bluetooth, səs, DNS, IP və xarici disk qaydalarını istifadə edin. Bir şərt və ya hamısını eyni vaxtda tələb edin. Tam profillər saxlayın və ya hər şərtə profil, ekran və vaxt həddi təyin edin.

macOS şəbəkə adını qoruduğu üçün Wi-Fi qaydaları Məkan Xidmətləri icazəsi tələb edir. Drive Alive yalnız seçilən yazıla bilən disklərdə öz gizli işarəsini yeniləyir və söndürüləndə silir.

Əmrin dəqiq icra müddətini izləmək üçün işlədin /Applications/Awakepilot.app/Contents/MacOS/awakepilotctl run --name "My job" -- command. Əmr bitəndə ona aid qoruma dayanır. Başqa aktiv işlər Mac-ı oyaq saxlaya bilər.

Cihaz və şəbəkə qaydalarını Avtomatlaşdırmada seçin. Bluetooth macOS icazəsi istəyir; səs cari çıxışı izləyir. DNS dəqiq ünvanları, IP isə IPv4, IPv6 və CIDR şəbəkələrini qəbul edir.

Tətbiq qaydası tətbiqdən çıxanadək davam edir; pəncərəni bağlamaq kifayət deyil. CPU və şəbəkə fəaliyyət ölçür, işin bitdiyini təsdiqləmir. “Bütün şərtlər” rejimində biri bitəndə qayda dayanır. Müstəqil işlər Mac-ı oyaq saxlaya bilər.

Sınaq, aktivləşdirmə və alış bərpası

Pro on dörd günlük sınaq verir. Sonra əl ilə sessiyalar qalır; saxlanmış avtomatlaşdırma parametrləri Mac-da qalır, amma işləmək üçün Pro tələb edir.

  • Awakepilot → Tərcihlər → Lisenziya və Pro açın.
  • Tam lisenziya açarını yapışdırın və Lisenziyanı aktivləşdir seçin.
  • Daimi şəxsi lisenziya iki Mac-da istifadə edilə bilər.
  • Yenisini aktivləşdirməzdən əvvəl lisenziyanı köhnə Mac-dan silin.

Lisenziya açarı, alış e-poçtu və əməliyyat ID-sini açıq GitHub sorğusunda paylaşmayın. Pro satışı başlayanda alış bərpası şəxsi müştəri portalında olacaq.

Pro məlumatlarına bax

Mac yenə yuxuya keçirsə

Yaşıl vəziyyət panelini yoxlayın. Batareya hədləri, adapter və UPS qaydaları sessiyanı dayandıra bilər.

MacBook qapağını bağlamaq, Apple menyusundan yuxu seçmək və kritik batareya Mac-ı yenə yatıra bilər. Awakepilot bu təhlükəsizlik davranışlarını dəyişmir.

Ekranın sönməsi sistem yuxusu və kilidlənmədən ayrıdır. Mac işləyə bilər; macOS kilid parametrləri qüvvədə qalır.

Yeniləmələr və ilk açılış

İstifadə edin: Haqqında və yeniləmələr sağ klik menyusundan. Quraşdırmadan əvvəl yoxlama cəmi, tətbiq kimliyi, Developer ID imzası və Gatekeeper təsdiqi yoxlanılır.

macOS əl ilə yüklənən nüsxəni bloklayırsa, silin və Buraxılışlar səhifəsindən rəsmi təsdiqlənmiş DMG-ni quraşdırın.

Tətbiq açıq olduqda hər 24 saatda, vaxtı çatıbsa oyananda avtomatik yoxlanılır. Quraşdırma vaxtını siz seçirsiniz. Yükləmə adətən bir dəqiqədən az çəkir; zəif bağlantıda uzana bilər.

0.14.0 və ya əvvəlki versiyadan yeniləmə Yeniləmə quraşdırılır vəziyyətində bir dəqiqədən çox qalırsa, bağlayın: Haqqında və yeniləmələr, sonra menyu sətrindən Awakepilot-dan çıxın. Hazır yeniləmə tamamlanıb tətbiqi yenidən aça bilər. Əks halda son rəsmi DMG-ni quraşdırın. 0.14.1 sonrakı yeniləmələr üçün bu problemi düzəldir.

Diaqnostika hesabatı yaradın

Açın: Haqqında və yeniləmələr, sonra seçin: Diaqnostik hesabatı saxla. Paylaşmazdan əvvəl JSON faylını yoxlayın.

Hesabatda əmr, nəticə, fayl yolu, Wi-Fi və disk adları, profillər, izlənən tətbiq və proseslər, cihazlar, DNS, IP qaydaları və fəaliyyət tarixçəsi yoxdur.

Hələ kömək lazımdır?

Awakepilot və macOS versiyası, Mac modeli və təkrarlama addımları ilə GitHub sorğusu açın. Faydalıdırsa yoxlanmış hesabat əlavə edin.
