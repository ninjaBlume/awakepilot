0.14.2

Son8 oktyabr 2026

On interfeys dili və Awakepilot saytından yeniləmələr.

Dörd yeni dil

  • İtalyan, Braziliya portuqalcası, yapon və Koreya dilləri əlavə edildi. Tətbiq artıq on dili dəstəkləyir.
  • 559 interfeys mətni və iki macOS icazə təsviri hər yeni dilə tərcümə edildi.
  • İtalyan və portuqal seçim mətnləri tam görünsün deyə qısaldıldı.

Yeniləmələr və yükləmələr

  • Yoxlamalar və rəsmi paket yükləmələri artıq awakepilot.codentum.net istifadə edir.
  • Buraxılış qeydləri tətbiqə görə ingilis, alman və ya türk dilində açılır; digər dillər ingilis dilindən istifadə edir.
  • Əvvəlki quraşdırmalar üçün GitHub Releases qalır. SHA-256, tətbiq kimliyi, Developer ID və Gatekeeper yoxlamaları saxlanılır.

0.14.1

1 oktyabr 2026

Etibarlı tətbiqdaxili yeniləmələr və daha aydın idarəetmə.

Etibarlı yeniləmələr

  • Haqqında və yeniləmələr pəncərəsinin çıxışı əngəlləyərək quraşdırmanı saxlaması düzəldildi. Pəncərə artıq quraşdırıcıya keçməzdən əvvəl bağlanır.
  • Çıxış ləğv edilərsə, beş saniyə sonra aydın xəta göstərilir. Quraşdırıcı da 30 saniyədən sonra gözləməyi dayandırır.
  • Açıq tətbiq hər 24 saatda, vaxtı çatıbsa oyananda yoxlayır. Avtomatik uğursuzluqda bir saat sonra təkrar edir; əl ilə yoxlama qalır.
  • Aktiv işlər, yeniləmə hazırlanarkən başlayanlar da daxil olmaqla, quraşdırmanı əngəlləyir.

Daha aydın idarəetmə və yardım

  • Ekran, fəaliyyət hədləri, şərtlərin uyğunluğu və müddətlər üçün ingilis, alman, ispan, fransız, Azərbaycan və türk mətnləri yeniləndi.
  • Uzun təsvirlərin sətirə bölünməsi yaxşılaşdırıldı.
  • İngilis, alman və türk sayt, dəstək və ekran görüntüləri yeniləndi.
0.14.0 və ya əvvəlki versiyadan yeniləmə

İlk yeniləmə hələ quraşdırılmış köhnə yeniləyicini istifadə edir. Yeniləmə quraşdırılır bir dəqiqədən çox qalırsa, Haqqında və yeniləmələr pəncərəsini bağlayıb menyu sətrindən çıxın. Hazır yeniləmə bitib tətbiqi aça bilər. Əks halda Yüklə düyməsindən son rəsmi DMG-ni quraşdırın. Düzəliş 0.14.1 quraşdırılandan sonra qüvvəyə minir.

0.14.0

1 oktyabr 2026

Avtomatlaşdırma qoşulu cihazlara, səs çıxışlarına və aktiv şəbəkə parametrlərinə genişləndirildi.

Əsas yeniliklər

  • Seçilən USB cihazı qoşulanda başlayın.
  • Seçilən cütləşdirilmiş Bluetooth cihazlarının qoşulmasını və ayrılmasını izləyin.
  • Seçilən macOS səs çıxışı aktiv olduqda sessiyanı saxlayın.
  • Aktiv konfiqurasiyada seçilən DNS server ünvanlarını yoxlayın.
  • Dəqiq IPv4, IPv6 ünvanlarını və CIDR şəbəkələrini yoxlayın.
  • Hər yeni şərtə ayrıca profil, ekran siyasəti və maksimum müddət təyin edin.
  • Yeni cihaz və şəbəkə qaydalarını təkrar istifadə edilən profillərdə saxlayın.
  • İngilis, alman, ispan, fransız, Azərbaycan və türk dillərində tam interfeys.
  • Böyük ikonlar, quraşdırma oxu və Retina fonu olan disk təsviri.

Məxfilik və icazələr

USB və səs yerli macOS API-lərindən istifadə edir. Bluetooth standart icazə ilə yalnız qoşulu cütləşdirilmiş cihazları yoxlayır. Cihaz adları, DNS və IP qaydaları macOS hesabında qalır. Hesabatlar yalnız qayda sayı və aktivlik vəziyyətini göstərir; adlar, DNS, IP qaydaları və tarixçə daxil edilmir.

0.13.0

1 oktyabr 2026

Şəbəkə və xarici yaddaş avtomatlaşdırması, tam konfiqurasiyalar üçün təkrar istifadə edilən profillər.

Əsas yeniliklər

  • Seçilən Wi-Fi şəbəkələrində başlayın.
  • İstənilən aktiv macOS VPN xidmətini izləyin.
  • Seçilən xarici disk qoşulanda sessiya başlayın.
  • Drive Alive seçilən yazıla bilən disklərdə öz işarəsini 5–60 dəqiqə aralıqlarla yeniləyir.
  • Tam parametrləri adlandırılmış profil kimi saxlayıb bərpa edin.
  • Tətbiq, proses, cədvəl, CPU, şəbəkə, enerji, ekran, Wi-Fi, VPN və disk üçün ayrıca profil, ekran və müddət.
  • Lokal tarixçədə vacib başlama, dayanma, fasilə və şərt dəyişiklikləri.
  • Shortcuts-da yerli aşkarlanma üçün App Intents və App Shortcuts provayderi paketə daxil edildi.

Təhlükəsizlik və məxfilik

Wi-Fi, disk və profil adları macOS hesabında qalır. Drive Alive yalnız öz imzalı sahiblik işarəsini dəyişir və söndürüləndə silir. Hesabatlarda Wi-Fi, disk, tətbiq, proses və profil adları yoxdur.

Yeni quraşdırıcı — 1 oktyabr 2026

İmzalı və təsdiqlənmiş DMG artıq böyük tətbiq və Applications ikonları, aydın ox və Retina fonu ilə açılır. Tətbiq 0.13.0 olaraq qalır; ZIP dəyişməyib. DMG-nin SHA-256 cəmi yeniləndi.

0.12.0

1 oktyabr 2026

Xarici idarəetmə, proses qaydaları və uzun əmrlər üçün məhdud qoruma əlavə edildi.

Əsas yeniliklər

  • Shortcuts-da Open URL vasitəsilə başlat, dayandır, dəyiş və uzat əmrləri.
  • awakepilot:// sxemi və paketdəki awakepilotctl terminal aləti.
  • Sahib proses bitəndə avtomatik buraxılan müddətli qoruma.
  • awakepilotctl run -- <command> əmri bütün icrası boyunca qoruyur.
  • Tənzimlənən terminal proses qaydaları.
  • Bir şərt və ya bütün şərtlərin uyğunluğu.
  • Adapter və qoşulu ekran avtomatlaşdırması.
  • Kritik istilikdə fasilə və avtomatik sessiyanın maksimum müddəti.
  • Menyu sətrində könüllü qalan vaxt və avtomatik sessiya yazıları.

Təhlükəsizlik və məxfilik

Qoruma 24 saatla məhdudlaşır. awakepilotctl run qoruması proseslə bitir, sahibsiz qoruma da təmizlənir. Qaydalar yalnız icra faylı adlarını müqayisə edir; əmr və nəticə saxlanmır. Hesabatlar izlənən tətbiq və proses adlarını gizlədir.
