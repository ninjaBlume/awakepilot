Fəaliyyətiniz Mac-ınızda qalır.

Fəaliyyətin Mac-də qalır. Quraşdırma sayğacı istəyə bağlıdır və standart olaraq bağlıdır. Rəy yalnız formanı göndərdikdə ötürülür.

Məxfilik xülasəsi

  • Awakepilot hesabı tələb olunmur.
  • Reklam və davranış izlənməsi yoxdur. Quraşdırma sayğacı istəyə bağlıdır.
  • Tarixçə və parametrlər macOS hesabınızda qalır.
  • Awakepilot şəxsi məlumatları satmır.

Lokal saxlanılan məlumatlar

Parametrlər, sessiya vəziyyəti, son ölçmələr və məhdud tarixçə macOS hesabında saxlanılır. Qaydalarda Wi-Fi adları, disk ID-ləri, profil adları, cihaz kimlikləri, DNS və IP şəbəkələri ola bilər.

Əmrin mətni və nəticəsi tarixçəyə yazılmır. Drive Alive kiçik .awakepilot-drive-alive işarəsini hər seçilən yazıla bilən diskdə yaradır və söndürüləndə silir.

Şəbəkəyə giriş

0.14.2-dən başlayaraq Awakepilot son versiyanı awakepilot.codentum.net-də yoxlayır və imzalı paketləri oradan yükləyir. Əvvəlki açıq versiyalar GitHub Releases istifadə edir.

Sayt GitHub Pages-də yerləşir. GitHub öz məxfilik siyasətinə uyğun IP kimi adi bağlantı məlumatlarını ala bilər. Awakepilot istifadə hadisələri göndərmir.

Diaqnostika hesabatları

Hesabat yalnız siz istəyəndə və saxlama yerini seçəndə yaradılır. Avtomatik yüklənmir.

Hesabatlarda əmrlər, nəticələr, yollar, Wi-Fi, disk, profil, tətbiq, proses və cihaz adları, DNS, IP qaydaları və tarixçə yoxdur. Dəstəyə paylaşmazdan əvvəl faylı yoxlayın.

Sistem icazələri

Bildirişlər könüllüdür. Wi-Fi adını oxumaq Məkan Xidmətləri icazəsi tələb edir; koordinatlar istənmir və saxlanmır. Sessiyalar adi istifadədə administrator tələb etməyən yerli enerji API-lərindən istifadə edir.

Girişdə başlatma Apple-ın yerli qeydiyyat xidmətindən istifadə edir. Qlobal qısayol Əlçatanlıq və ya klaviatura izləmə icazəsi tələb etmir.

Bluetooth avtomatlaşdırması macOS icazəsi tələb edir və qoşulu cütləşdirilmiş cihazları lokal yoxlayır. USB, səs, DNS və IP lokal sistem məlumatlarından istifadə edir.

İstəyə bağlı quraşdırma sayğacı

Standart olaraq bağlıdır; 0.15.0 versiyasından etibarən Tərcihlərdə mövcuddur. Aktiv olduqda Awakepilot açıq olduğu hər UTC günündə bir dəfə təsadüfi quraşdırma kodu göndərir. Yalnız tarix və kodun gizli açarla hesablanan xülasəsi saxlanılır. Ad, e-poçt, avadanlıq kimliyi, oyaq saxlama sessiyası, avtomatlaşdırma qaydası və ya sistem ölçümü toplanmır. İştirak edən aktiv quraşdırmalar sayılır; iki Mac iki quraşdırma sayılır.

Gündəlik qeydlər 90 gün sonra silinir. Ayarı bağlamaq göndərişi dayandırır, yerli kodu silir və əlaqə olduqda əvvəlki qeydlərin silinməsini tələb edir. Gecikmiş sorğuların qeydləri bərpa etməməsi üçün kodun xülasəsi ilə ləğv qeydi 90 gün saxlanılır. Yenidən aktivləşdirmə yeni kod yaradır.

Rəy forması

Forma mövzu, mesaj, dil, istəyə bağlı e-poçt və tətbiq versiyasını göndərir. Bunlar problemləri və təklifləri araşdırmaq, istənildikdə cavab vermək üçün istifadə olunur. Mesajlar ən çox 180 gün saxlanılır və ya ehtiyac qalmadıqda daha tez silinir. Baxış, düzəliş və silinmə üçün hello@codentum.net ünvanına yaz; e-poçt verməmisənsə göndəriş nömrəsini əlavə et. Rəy heç vaxt quraşdırma kodu ilə əlaqələndirilmir.

Cloudflare sayğac və rəy xidmətini yerləşdirir; sorğuları ötürmək və qorumaq üçün IP ünvanı kimi əlaqə məlumatlarını emal edir. Verilənlər bazamızda IP ünvanları saxlanılmır. Forma spamdan qorunmaq üçün Cloudflare Turnstile istifadə edir. Sorğu jurnalları bağlıdır. Reklam və davranış profilləri yaradılmır.
