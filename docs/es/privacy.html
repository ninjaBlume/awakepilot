Privacidad

Tu actividad se queda en tu Mac.

Awakepilot funciona sin cuenta y no incluye publicidad, analítica, seguimiento ni telemetría.

ResumenDatos localesRedDiagnósticoPermisosIntegridad

Resumen de privacidad

  • No necesitas una cuenta de Awakepilot.
  • No incluye publicidad, SDK de analítica, píxeles de seguimiento ni servicios de telemetría.
  • Tu historial de actividad y tus preferencias se guardan en tu cuenta de usuario de macOS.
  • Awakepilot no vende ni comparte datos personales.

Datos guardados localmente

Awakepilot guarda las preferencias, el estado de las sesiones, las mediciones recientes del sistema y un historial limitado de actividad en tu cuenta de usuario de macOS. Los ajustes de automatización pueden incluir nombres de redes Wi-Fi, identificadores de volúmenes, nombres de perfiles, identidades de dispositivos elegidos, servidores DNS y reglas de redes IP.

Los textos y las salidas de comandos no se guardan en el historial de actividad. Drive Alive crea un pequeño archivo marcador llamado .awakepilot-drive-alive en cada unidad elegida con permiso de escritura y elimina su marcador al desactivar la función.

Acceso a la red

Awakepilot 0.14.2 y posteriores consultan la última versión publicada en awakepilot.codentum.net y descargan los paquetes de actualización firmados desde el mismo sitio. Las versiones públicas anteriores usan GitHub Releases.

El sitio se aloja en GitHub Pages. GitHub puede recibir datos normales de conexión, como tu dirección IP, según su propia política de privacidad. Awakepilot no envía eventos de uso con estas solicitudes.

Informes de diagnóstico

Solo se crea un informe cuando lo solicitas y eliges dónde guardarlo. Nada se sube automáticamente.

Los informes no incluyen textos ni salidas de comandos, rutas de archivos, nombres de redes Wi-Fi, volúmenes, perfiles de automatización, apps y procesos supervisados, nombres de dispositivos, servidores DNS, reglas IP ni historial de actividad. Revisa el archivo antes de compartirlo con soporte.

Permisos del sistema

El permiso de notificaciones es opcional. Leer el nombre de la red Wi-Fi actual requiere permiso de Localización de macOS; Awakepilot no solicita ni guarda coordenadas geográficas. Las sesiones usan las API nativas de gestión de energía de macOS y no necesitan acceso de administrador en el uso habitual.

El inicio de sesión usa el registro de servicios nativo de Apple. El atajo global no necesita permisos de Accesibilidad ni de supervisión del teclado.

La automatización Bluetooth requiere el permiso Bluetooth habitual de macOS y comprueba localmente los dispositivos emparejados conectados. Las reglas de USB, salida de audio, DNS e IP usan información local del sistema.

Integridad de las versiones

Los paquetes oficiales de Awakepilot están firmados con un certificado Developer ID, notarizados por Apple y publicados con sumas de comprobación SHA-256. El historial público incluye las notas de cada versión y sus paquetes de descarga.
