インストールメニューバー自動化ライセンススリープの動作更新診断問い合わせ

Awakepilotのインストール

公式の公証済みDMGを開き、Awakepilotをアプリケーションフォルダへドラッグします。「ログイン時に起動」を有効にする前に、そのフォルダから起動してください。

Apple SiliconとIntelのMacで、macOS 13以降に対応します。

メニューバーのアイコンを探す

Awakepilotはメニューバーで動作し、Dockには表示されません。画面右上の時計アイコンを探してください。

  • 左クリックでコンパクトな操作パネルを開きます。
  • 右クリックでセッション、クイックタイマー、システム指標の設定を開きます。
  • 塗りつぶされた時計はスリープ防止中の印です。

「セッションを停止」はそのセッションを終了し、再開するまでルールを一時停止します。コマンドや転送は中断せず、それらが引き続きスリープを防ぐ場合があります。保護解除で即座にスリープすることはありません。

長い作業を自動化

アプリ、プロセス、時刻、CPU、通信、電源、画面、Wi-Fi、VPN、USB、Bluetooth、音声、DNS、IP、外部ドライブのルールを使用できます。ひとつの成立か、すべて同時の成立を選択。設定一式を保存するか、条件ごとにプロファイル、画面、時間上限を指定します。

macOSがWi-Fi名へのアクセスを保護するため、Wi-Fiルールには位置情報の許可が必要です。Drive Aliveは選んだ書き込み可能なドライブで専用の隠しマーカーだけを更新し、無効化時に削除します。

コマンドの実行時間を正確に追跡するには、次を実行します： /Applications/Awakepilot.app/Contents/MacOS/awakepilotctl run --name "My job" -- command。コマンド終了時にその保護を解除します。ほかの作業が引き続きスリープを防ぐ場合があります。

自動化で機器と通信ルールを選びます。BluetoothはmacOSの許可が必要で、音声は現在の出力経路を追跡します。DNSはアドレスを完全一致で比較し、IPはIPv4、IPv6、CIDRに対応します。

アプリルールはアプリの終了まで続き、ウィンドウを閉じるだけでは終了しません。CPUと通信は活動量を測り、作業完了は確認しません。「すべての条件」ではひとつが終了するとルールを解除します。独立したジョブは保護を続ける場合があります。

体験版、有効化、購入の復元

Proは14日間体験できます。終了後も手動セッションは利用可能です。保存した自動化設定はMacに残りますが、実行にはProが必要です。

  • Awakepilot → 設定 → ライセンスとProを開きます。
  • ライセンスキー全体を貼り付け、「ライセンスを有効にする」を選びます。
  • 個人向け永続ライセンスはMac 2台まで利用できます。
  • 別のMacで有効化する前に、古いMacから解除してください。

公開GitHub Issueにキー、購入メール、取引IDを投稿しないでください。購入復元はPro販売開始時の非公開顧客ポータルで行う予定です。

Macがまだスリープする場合

緑色の状態パネルを確認します。バッテリー上限、電源アダプタ、UPSのルールでセッションが一時停止する場合があります。

MacBookのふたを閉じる、Appleメニューからスリープを選ぶ、バッテリーが危険な残量に達する場合は、スリープできます。Awakepilotはこれらの安全動作を変更しません。

画面の消灯は、システムのスリープや画面ロックとは別です。作業は続けられますが、macOSのロック設定は有効なままです。

更新と初回起動

右クリックメニューの 情報とアップデート から更新を確認できます。インストール前にチェックサム、アプリ識別情報、Developer ID署名、Gatekeeperの承認を検証します。

手動で取得したコピーをmacOSがブロックする場合は削除し、リリースページの公式公証済みDMGを入れ直してください。

起動中は24時間ごと、または確認時刻を過ぎたスリープ復帰時に自動確認します。インストール時刻は選べます。通常は1分未満で取得でき、遅い回線では長くなります。

0.14.0以前からの更新が アップデートをインストール中 のまま1分以上続く場合、閉じてください： 情報とアップデート。続いてメニューバーからAwakepilotを終了します。準備済みの更新が完了し、再起動できます。進まなければ最新の公式DMGを入れてください。0.14.1では以降の更新の問題を修正しています。

診断レポートの作成

開きます： 情報とアップデート。次に選びます： 診断レポートを保存。共有前にJSONファイルを確認してください。

コマンド、出力、パス、Wi-Fi・ボリューム名、プロファイル、監視アプリ・プロセス、機器名、DNS、IPルール、活動履歴は含みません。

解決しない場合は

AwakepilotとmacOSのバージョン、Macのモデル、再現手順を添えてGitHub Issueを作成してください。役立つ場合は確認済みの診断レポートを添付します。
