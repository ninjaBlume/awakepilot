5つの設定済みテンプレート

いつもの作業から始めましょう。

ソフトウェア開発

ビルドは予想より長くかかることがあります。毎回タイマーの長さを見積もらず、プロセスを監視できます。

ビルドツールのテンプレートはxcodebuildまたはswiftを監視し、画面のスリープを許可して4時間を上限にします。特定のコマンドにはawakepilotctl runを使えます。

監視するプロセスがすべて終了するか4時間の上限に達すると、このテンプレートの条件が適用されなくなります。ビルド自体は中止しません。

動画制作

編集アプリが開いていることだけを条件にせず、画面を消したまま書き出しを続けられます。

動画エンコードのテンプレートはffmpegを監視し、画面のスリープを許可して4時間を上限にします。別のエンコーダーにはそのプロセス名を選んでください。

監視プロセスがなくなるか上限に達すると、このルールの保護が終了します。書き出しの成功を確認するものではありません。

ファイル転送とバックアップ

長いコピーは短いタイマーを超えることがあります。転送プロセスを監視し、外付けドライブを明示的に選べます。

ファイル転送のテンプレートはrsyncを最大4時間監視します。Drive Aliveはオフのままです。選んだ書き込み可能なドライブだけで別途有効にしてください。

rsyncが終了するか上限に達すると、このルールは終了します。ドライブルールはマウント状態を監視し、コピーの完了を確認しません。

残る2つはダウンロードとプレゼンテーションのテンプレートです。繰り返す作業には名前付きプロファイルを保存し、Mac間で書き出し・読み込みできます。読み込みは保存だけで、設定を適用しません。他の作業やルールでMacが起動状態のままになる場合があります。

開始、停止、変化を確認。

状態をいつでも把握できます。Awakepilotは意味のある変化を記録し、CPUや通信の毎回の測定で履歴を埋めません。

1つのコマンドにスリープ防止を紐づける。

無料版でも利用できます。Awakepilotを開いた状態でawakepilotctlからコマンドを実行すれば、所要時間の見積もりが不要です。

/Applications/Awakepilot.app/Contents/MacOS/awakepilotctl run --name "Build" -- xcodebuild -scheme MyApp
1

コマンドを開始

Awakepilotはコマンドの開始前に名前付きの起動維持リースを作成します。

2

有効な理由を確認

Macを起動状態に保つ理由として、パネルにリース名が表示されます。バッテリーと温度の保護は引き続き適用されます。

3

その保護を解除

コマンドが終了すると、そのリースが解除されます。他のセッションや作業は続く場合があり、macOSに即座のスリープを指示しません。

これはコマンドの例で、録画ではありません。MyAppを自分のスキーム名に置き換えてください。リースは標準で最大24時間、--ttlで短縮できます。期限切れはコマンドを中止せず、保護だけを解除します。

蓋を閉じたまま作業

標準モードは無操作による自動スリープを防ぎます。蓋を閉じる動作とスリープの選択はmacOSが制御します。画面のスリープと画面ロックは別の設定です。

任意の蓋閉じモードは標準でオフです。有効な間は外部ディスプレイがなくても動作し、Appleメニューのスリープも防ぎます。
