0.14.2

最新2026年10月8日

10言語のインターフェイスと、Awakepilotサイトで配信する更新。

4言語を追加

  • イタリア語、ブラジルポルトガル語、日本語、韓国語を追加。10言語に対応しました。
  • 各言語で559件の表示テキストと2件のmacOS権限説明を翻訳しました。
  • イタリア語とポルトガル語の長い選択ラベルを短くし、全体を表示します。

更新とダウンロード

  • 更新確認と公式パッケージの取得先をawakepilot.codentum.netに変更しました。
  • アプリの言語に応じて英語、ドイツ語、トルコ語のノートを開き、ほかは英語を使います。
  • 旧版向けにGitHub Releasesも継続。SHA-256、アプリ識別情報、Developer ID、Gatekeeperの検証を維持します。

0.14.1

2026年10月1日

確実なアプリ内更新と、わかりやすい操作。

確実な更新

  • 情報とアップデート画面が終了を妨げ、更新が止まる問題を修正。更新処理に渡す前に画面を閉じます。
  • 終了がキャンセルされると5秒後に対処可能なエラーを表示。インストーラーの待機も30秒で終了します。
  • 起動中は24時間ごと、期限を過ぎた復帰時にも確認。自動確認の失敗は1時間後に再試行し、手動確認も利用できます。
  • 準備中に開始したものを含め、実行中のジョブはインストールを防ぎます。

操作とヘルプの改善

  • 英語、ドイツ語、スペイン語、フランス語、アゼルバイジャン語、トルコ語で、画面動作、活動値、条件判定、時間上限の説明を改善しました。
  • 長い設定説明の折り返しを改善しました。
  • 英語、ドイツ語、トルコ語のサイト、サポート、画像を更新しました。
0.14.0以前からの更新

最初の更新には旧版の更新機能を使用します。アップデートをインストール中が1分以上続く場合は、情報とアップデートを閉じてメニューバーから終了してください。準備済みの更新が完了して再起動できます。進まない場合はダウンロードボタンから最新の公式DMGを入れてください。修正は0.14.1の導入後に有効になります。

0.14.0

2026年10月1日

自動化の対象を接続機器、音声出力、現在のネットワーク設定に拡張。

主な変更

  • 選択したUSB機器の接続で開始。
  • 選択したペアリング済みBluetooth機器の接続・切断を追跡。
  • 選択したmacOS音声出力が使用中の間、セッションを維持。
  • 現在のDNS設定から選んだサーバーアドレスを照合。
  • IPv4、IPv6アドレスの完全一致とCIDRネットワークを照合。
  • 新しい条件ごとにプロファイル、画面方針、時間上限を独立指定。
  • 新しい機器・通信ルールを再利用可能なプロファイルに保存。
  • 英語、ドイツ語、スペイン語、フランス語、アゼルバイジャン語、トルコ語で全画面に対応。
  • 大きなアイコン、ドラッグ矢印、Retina背景付きのディスクイメージ。

プライバシーと権限

USBと音声はmacOSのローカルAPIを使用。Bluetoothは標準権限を受け、接続中のペアリング済み機器だけを確認します。機器名、DNS、IPルールはmacOSアカウントに残ります。診断はルール数と有効状態だけを含み、名前、DNS、IPルール、履歴を除外します。

0.13.0

2026年10月1日

ネットワークと外部ストレージに自動化を拡張し、設定一式を保存するプロファイルを導入。

主な変更

  • 選択したWi-Fiネットワークで開始。
  • 有効なmacOS VPNサービスを追跡。
  • 選択した外部ボリュームのマウントで開始。
  • Drive Aliveが選択した書き込み可能なボリュームの専用マーカーを5〜60分ごとに更新。
  • 設定一式を名前付きプロファイルとして保存・復元。
  • アプリ、プロセス、時刻、CPU、通信、電源、画面、Wi-Fi、VPN、ドライブに独立したプロファイル、画面方針、上限を指定。
  • 開始、停止、一時停止、条件変化をローカル履歴で確認。
  • ショートカットで標準認識できるよう、App IntentsとApp Shortcutsプロバイダーを同梱。

安全性とプライバシー

Wi-Fi、ボリューム、プロファイル名はmacOSアカウントに残ります。Drive Aliveは署名された所有マーカーだけを更新し、無効化で削除。診断ではWi-Fi、ボリューム、アプリ、プロセス、プロファイル名を除外します。

インストーラー刷新 — 2026年10月1日

署名・公証済みDMGを、大きなアプリとアプリケーションのアイコン、明確な矢印、Retina背景に変更。アプリは0.13.0のままで、ZIPは変更ありません。DMGのSHA-256を更新しました。

0.12.0

2026年10月1日

外部制御、プロセス条件、長いコマンド向けの時間制限付き保護を追加。

主な変更

  • ショートカットのURLを開く操作で、開始、停止、切り替え、延長。
  • awakepilot:// URL方式と同梱CLIのawakepilotctl。
  • 所有プロセスの終了で自動解除する期限付き保護。
  • awakepilotctl run -- <command>でコマンド実行中を保護。
  • 設定可能なターミナルプロセス条件。
  • いずれかの条件、またはすべての条件で判定。
  • 電源アダプタと接続ディスプレイの自動化。
  • 危険な温度状態で一時停止し、自動セッションの最大時間を設定。
  • メニューバーに残り時間と自動セッションのラベルを任意表示。

安全性とプライバシー

保護の上限は24時間。awakepilotctl runは所有プロセス終了で解除し、孤立した保護も整理します。プロセス条件は実行ファイル名だけを比較し、コマンドや出力は保存しません。診断は監視アプリ・プロセス名を除外します。
