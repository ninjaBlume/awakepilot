# Awakepilot

Awakepilot keeps a Mac awake while real work needs it. It supports manual
sessions, system activity, applications, terminal processes, schedules, Wi-Fi,
VPNs, displays, power conditions, external drives, and safety limits.

## Download

Download the latest signed and Apple-notarized release from
[Awakepilot Releases](https://github.com/ninjaBlume/awakepilot/releases/latest).
